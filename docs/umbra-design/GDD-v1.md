【幽影协议 UMBRA · 重制策划案 v1】
主策划：红色 P5R 方｜拍板：用户｜执行：App 集成 AI、黄（P4）/蓝（P3）/粉（P3P）主题 AI
依据：现有幽影协议盘点、P5X 拆解、Web 技术调研（三份调研报告在 design/ 目录）

━━━━━━━━━━━━━━━━
一、一句话
白天在 MASKARIA 里认真生活，夜里在幽影协议里变强。一款手机横屏、单次 5–15 分钟、演出对标 P5X 的 2D 回合制 RPG。四个主题是同一个游戏，各自换皮换演出。

二、为什么推倒重来（现状结论）
1. 卡：四套主题 CSS 同时加载（约 1.9MB），每次行动整块重建几百个网页元素，样式重算约 300ms，base 本身也是 304ms。底层路线错了，修不好。
2. 素：特效靠 CSS 堆，手机扛不住，只能砍演出。攻击只有文字，没有画面。
3. 不好玩：只按普攻，1–38 层胜率 96–100%；五维、地图增益都没算进伤害；交涉有三套实现，显示的概率和实际概率不一样。
4. 不适合手机：跑完一趟要 1.5–2.5 小时，塔门每周只开 3 晚，失败清空进度；真实生活的成长没有反馈到游戏里。
值得留下的：P5 压制链（弱点 → 1 MORE → 接力 → HOLD UP），敌人意图预告，P5R 合成表，AI 自由交涉（独有卖点），种子地图的骨架。

三、四大支柱（所有决策都拿这四条检验）
① 生活即战力：App 里的五维和 SP 直接决定游戏里的强度和资源。
② P5X 级手感：每个动作都有画面，打击感优先，满配 ≥30fps、目标 60fps。
③ 碎片化：随开随玩、随时退出；每个节点自动存档；不设体力墙。
④ 一套游戏、四种风味：规则和引擎共享，主题只负责「长什么样、怎么演」。

四、核心循环
【每日入口 · 委托板】1–2 分钟一个，每天 3 个
打开游戏先看到 3 张委托卡，每张一场预设弱点战，鼓励一回合内打出总攻，打完立即结算。奖励面具碎片和经验。连续 3 天完成，送一张「强化预告信」。

【主循环 · 潜入】8–12 分钟一局（P5 叫潜入殿堂，P3 叫攀登塔层，P4 叫电视世界，规则相同）
1. 出发（20 秒）：选目标（每周轮换 3 个主题异界），查看 BOSS 弱点提示，编队 4 人，再选 1 个导航被动。
2. 节点地图（4–5 个节点，每个 1–2 分钟）：2.5D 插画地图，Q 版角色沿路线移动，镜头跟随。节点类型：杂兵战（可偷袭先手或绕开）、精英战（带护盾）、安全屋（回复并存档）、机关（10 秒内能解的小谜题）、交涉点。
3. 局内选卡：每场战斗后三选一「心之卡」，例如火伤 +20%、1 MORE 追击翻倍、必杀充能 +30%。这是重玩性的来源。
4. 主战：BOSS 分两阶段，第二阶段切专属 BGM，播必杀演出。
5. 结算（30 秒）：按回合数和受伤量评级，掉落面具和素材，增加怪盗等级经验。
中断规则：每个节点自动存档，切出去回来从当前节点开头继续。
失败规则：保留本局已获奖励的一半，可从最近的安全屋免费重试一次。不再清空进度。

【挑战层 · 天鹅绒试炼】2–5 分钟一关，每周 5 关
手工设计的战斗谜题，给定队伍，目标如「3 回合内击败」「一次总攻清场」，按表现给 1–3 星。兼做新手教学。

【首局体验】开场 30 秒剧情（视觉小说式立绘）→ 60 秒内进入教学战 → 第 3 分钟看到第一次总攻定格画 → 第 6–8 分钟打完一局迷你潜入。

五、战斗系统
- 队伍：主角 + 3 名同伴，按速度排行动顺序，顺序条在左上。
- 面具：每个面具 3 个主动技能 + 1 个被动，技能列表不需要滚动。主角可带 3 个面具，战斗中切换。
- 压制链：命中弱点或暴击 → 敌人倒地 → 1 MORE。1 MORE 按 P5X 规则做：选一名队友打一记固定追击，或者自己再行动一次，每人每轮限一次。
- 护盾：只给精英和 BOSS，最多 3 层，要多次命中弱点才能打倒。
- 必杀（HIGHLIGHT）：每人一个，靠造成和承受伤害充能，满了可以随时插队，用完冷却 4 回合。
- 全员倒地 → HOLD UP 二选一：
  · 总攻：角色依次冲刺斩击，结尾是专属定格画（招牌演出，必须保留）。
  · 交涉：沿用 AI 自由文字交涉，统一成一套实现，显示的概率 = 实际概率。成功可获得面具、钱或道具。
- 敌人意图：保留下回合行动预告。
- 自动战斗与 2/3 倍速：首次通关某个异界后解锁。
- 演出三档：完整（首次）、标准、极简（倍速或自动时）。同一种演出看过若干次后自动降档，也可以在设置里调。3 倍速下一场杂兵战 ≤15 秒。
- 难度目标（用无头模拟器校准）：
  · 只按普攻：第 3 个异界起明显打不过。
  · 正常利用弱点：胜率约 85–90%。
  · 精英：需要用到 1 MORE 或必杀。
  · BOSS：需要读意图、切面具。

六、生活桥（核心差异）
五维 → 角色属性（App 等级越高越强，带上限和平滑曲线，避免碾压）：
- 知识 → 魔攻、SP 上限
- 胆量 → 暴击率、异常抗性
- 灵巧 → 速度、命中
- 温柔 → 治疗量、防御
- 魅力 → 交涉成功率、商店折扣
App 里的 SP → 局外资源「心之力」，用于合成加速、面具强化、借面具。
今日状态：当天完成的真实待办和记录，换成当晚的 1–2 张开局增益卡（例如今天读了书，魔攻 +10%）。只加成，没做到也不惩罚。
影时间：从「门禁」改成「加成时段」。随时都能玩，影时间内掉落翻倍，并出现限定强敌。
货币不超过 3 种：¥（局内外通用）、素材（单一品阶体系）、心之力（来自生活）。

七、成长与收集
- 怪盗等级（账号等级）：解锁同伴、异界、天鹅绒功能。
- 面具：交涉和掉落获得，天鹅绒合成（P5R 合成表），技能继承界面补上。
- 同伴也会升级（现在只有出战面具拿经验，要修）。
- 去掉一堆 2–15% 的零碎加成，换成少而有感的选择。

八、画面与场景（横屏 16:9）
场景：标题 → 据点 → 委托板 → 出发编队 → 节点地图 → 战斗 → 交涉 → 结算 → 天鹅绒 → 图鉴 → 设置。每个场景都有进场、退场转场和加载画面。
据点只放 4 个大入口：出发、天鹅绒、商店、队伍。设置齿轮放右上角，要显眼。
战斗布局（照 P5X）：
- 左上：行动顺序条
- 右上：自动 / 倍速 / 暂停
- 敌人居中偏右，头顶显示弱点和护盾
- 我方角色在左下，用背影或半身
- 左下：队伍头像、HP、SP，只看不点
- 右下：拇指弧形区放 5–6 个按钮，主按钮 ≥96、次按钮 ≥84 设计像素（1280×720 基准；实机须 ≥44pt）
- 刘海和手势条范围内不放按钮
角色动画（第一阶段不用 Spine）：立绘用 AI 拆成约 5 层，再用网格形变做呼吸、发丝摆动、受击压扁回弹、出招前冲残影、倒地碎裂。以后有预算可以升级 Spine，代码接口不变。
演出时长目标：
- 开战转场 0.7–0.9 秒
- 普通技能 1.2–1.8 秒（命中停帧 60–90 毫秒）
- 1 MORE 横幅 0.45 秒
- 总攻 2.8–3.5 秒（结尾定格 0.8 秒）
- 必杀 2.5–3.5 秒，简短版约 1.2 秒
- 菜单切换 0.18–0.28 秒，动画播放中也能点下一项
避开 P5X 被骂的点：首局拖沓、地图过大、重复解谜、UI 信息堆满、连败没有保底、大招没法跳过。
音频：BGM 按场景切换；点击、选择、命中、暴击、1 MORE、总攻都有音效。

九、技术方案
- 渲染：PixiJS v8，固定 WebGL（gzip 后约 231KB），滤镜用 pixi-filters。备选 Phaser 4。不用 Unity、Cocos、纯 Canvas2D。
- 语言与构建：TypeScript + Vite，按场景分包。
- 规则层：合并成一份 TS（并入宿主 src/umbra/engine，去掉 @ts-nocheck，取消 JS/TS 双份）。规则层零 DOM、零画布，只发事件，配无头模拟器和回归测试。
- UI 取舍：会动、要跟演出同步的放画布（HUD、伤害数字、cut-in、转场）；文字多、要滚动、要输入的用 DOM 叠加（菜单、图鉴、交涉输入、设置）。DOM 只用 transform/opacity 做动效，演出期间冻结。
- 横屏：主 App 竖屏，进入游戏后由原生层锁横屏（Android SENSOR_LANDSCAPE + configChanges；iOS requestGeometryUpdate），退出恢复竖屏。
  风险：Android 16 平板和 iPadOS 26 可能拒绝锁屏，所以游戏必须自带「虚拟横屏」：竖屏时提示横置并暂停；如必须可玩，就在画布内整体旋转 90°。
- 性能纪律：
  · 同屏滤镜最多 2 个，分辨率=渲染分辨率×0.5，限时限区域
  · 粒子池化，图集，加载期预上传纹理、预编译滤镜，首次放技能不掉帧
  · 画质分高、中、低三档，按帧时间自动降档；降档不减演出种类，可减粒子数、渲染分辨率、滤镜分辨率
  · 手机纹理常驻 ≤256MB，首包 ≤2–3MB，图鉴数据分片
- 音频：首次触摸解锁；音效预解码；BGM 流式播放；格式用 AAC。

十、模块与接入契约（草案，M3 冻结）
目录：
umbra/
  engine/   引擎：初始化、主循环、场景管理、资源、特效原语、动画、音频、输入、布局与虚拟横屏、画质、原生桥
  rules/    规则：战斗、合成、经济、遇敌、交涉、地图、存档、生活桥换算、事件定义
  skins/    皮肤：_contract 接口定义；p5r-red、p3-blue、p3p-pink、p4-yellow 各一个包
  ui/       DOM 叠加层：菜单、图鉴、交涉、设置
皮肤包内容：manifest（素材清单）、palette（配色）、recipes（动作和特效配方，JSON 关键帧）、cutins（cut-in、总攻、1 MORE 版式）、scenes（各场景布景）、ui.css（只作用于本皮肤根节点）。
注册与切换：UMBRA.registerSkin(id, pack)；只加载当前主题，进游戏时按 App 主题选定。
引擎事件（皮肤订阅，返回 Promise，引擎等演出播完再推进，点击可跳过；主题没实现的事件由引擎默认演出兜底）：
- scene:enter / scene:leave
- battle:start / turn:start / action:windup / action:hit{dmg,weak,crit,miss,resist,element} / unit:down / onemore / highlight / holdup / allout:start / allout:end / talk:start / talk:result / battle:end
- map:move / map:encounter / ui:open / ui:close
宿主桥（postMessage，校验来源）：
- 父 → 子：主题、五维、心之力、今日状态、影时间、存档种子、安全区
- 子 → 父：存档回写、消耗心之力、退出、锁横屏/解锁、震动；AI 交涉请求（沿用现有 AI 桥）

十三、统一验收标准
- 横屏硬标准：手机横屏（667×375、844×390、915×412）和平板横屏（1024×768、1180×820）完整好看、拇指顺手；竖屏进入时正确横置或提示；桌面也要好看。
- 帧率：① CPU 4 倍降速下每帧主线程 ≤8ms（无头自动测）；② 真机（中端 Android、iPhone 11 级）最密集演出 ≥30fps，目标 60fps；首次放技能最长帧 ≤50ms（加载时在真实画布上快进预演一遍技能与总攻，转屏/改尺寸后重新预热）。
- 演出：满配，不为流畅砍演出种类；每个动作都有画面，文字只做辅助。
- 界面：不重叠、不遮挡按钮、血条和弱点信息，特效播完立即清场。
- 流程：委托 → 潜入 → 战斗 → 总攻/交涉 → 结算 → 回城，0 卡死、0 报错，连点不重复触发。
- 主题隔离：四主题互不影响，只加载当前主题。
- 数值：模拟器结果达到第五节的难度目标。

十五、v1.1 评审修订（10-22 00:50，依据 App 与黄、蓝、粉评审）
采纳并写入契约：
1. 不再用 iframe。新引擎作为同源 TS 模块，挂在 React 容器里，通过带类型的 UmbraRuntimeBridge 通信：父层传只读快照，子层回 commitRun / spendHeartPower / notifyError / exit。只有 AI 交涉可以继续单独走 postMessage。localStorage 存档桥退役。
2. 规则权威：皮肤演出事件可以等待，但每个事件有时长上限（随倍速缩放），超时由引擎强制推进；演出期间的输入进预缓冲队列。皮肤报错只影响画面，不影响胜负、掉落和消耗。
   时长上限：onemore ≤0.45s，allout ≤3.5s，highlight ≤3.5s，普通技能 ≤1.8s，开战转场 ≤0.9s。
3. 存档改用版本化 UmbraSaveV4：永久资源和一局行程分开存，都带 schemaVersion、checkpointId 和幂等键。结算先写 Dexie 事务，再播演出。
4. 规则和数据只留一份：以 src/umbra/engine 的 TS 为准，去掉 @ts-nocheck，删除 public/umbra-demo 里对应的 JS。2.2MB 图鉴拆成分片动态加载。首包 ≤2–3MB 只算引擎、标题和当前皮肤。
5. 生活桥由 App 层生成只读派生快照：五维平滑映射到属性；今日卡按日期和局种子确定性抽取；影时间=倍率 + 限定敌表。心之力只在规则返回合法结果后才扣。
6. 横屏：自定义 Capacitor 插件负责锁定/解锁和沉浸模式，同时默认启用虚拟横屏（必须可用，不是可选兜底）。安全区读 env() + ResizeObserver。
7. 皮肤自由度：布局用「插槽 + 可覆盖样式 token」。指令区形状可以改（P3 斜列文字菜单、P4 方块菜单），只要命中区 ≥72 逻辑像素，且在安全区和拇指区内。
   新增顶栏信息插槽，用于 P4 的日期和天气。所有文案都可以按原作改名（委托板、心之卡、HOLD UP、异界名、怪盗等级），规则 id 不变。
