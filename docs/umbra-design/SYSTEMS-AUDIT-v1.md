# 幽影协议 UMBRA · 玩法完整性审计 v1（主策划，2026-10-22）

对照 P3R、P4G/P4R、P5R、P5X，把原作主要系统逐项列出，给出：原作怎么做 / 我们现状 / 决定 / 理由 / 落到哪个模块。
依据：GDD-v1（§四–§七、§17–§22）、docs/umbra-decisions.md（D-003～D-007）、docs/umbra-design/FX-MAP-v1.md、audit-umbra.md（旧版代码盘点）、src/umbra/engine 现有代码。

## 0. 怎么读

- **现状**：✅已有（规则或数据已在 TS 里，或 GDD/D 号已定稿）· ◐部分（有接口或旧 JS 有、新规则缺；或只有文档没规格）· ✗缺失。
- **决定**：保留（照原作）· 改造（保留原作语言，改成手机/生活桥版本）· 砍掉 · v2（要做，但不进 v1）。
- **模块**：rules/combat · rules/encounter · rules/explore · rules/fusion · rules/progression · rules/bond · rules/economy · rules/requests · rules/lifebridge · rules/save · skins/* · ui/* · data/*（数据表）· sim（模拟器）· FX（FX-MAP 事件）。
- **硬约束（每一项都已对过）**：AI 只写文字不定数值（§20）；同伴/专属面具按皮（D-005）；商店四类按 D-007；探索 = P5T 式 Q 版格子（D-003）；遭遇 1–5 只（D-004）；五层成长 + sim:balance 验收（D-006）；一局 8–12 分钟；货币只有 ¥ / 素材 / 心之力。
- 本文**不写任何具体数值**：所有倍率、价格、概率、时长以外的数字都进数据表，由 sim:balance 校准。时长上限沿用契约/FX-MAP。

### 4.2 合成改回原作（V1/V3/V5/V17）
- 合成消耗素材面具；合成免费；购回收 ¥。合成前界面明确写「这两张将消失」+ 图鉴是否已登记。
- 继承：结果 3 主动 + 1 被动；可替换格数按合成类型（二体/多体/警报）查表；候选只来自素材面具已学技能；禁继承规则读图鉴字段，缺字段时按对立属性（火↔冰、电↔风、祝↔咒、念↔核）禁止。
- 献祭：经验转移，被献祭面具消失；基础契约（初始/专属）面具不可献祭、不可电椅（沿用旧规则）。
- 库存上限随怪盗等级；满时战斗/交涉获得的面具进「待处理」区，回据点必须处理（不丢）。

### 4.3 天鹅绒羁绊与委托（V13）+ 特别处遇（V8）+ 禁闭（V6）
- 天鹅绒委托：每周若干条「交出带 X 技能、Y 阿尔卡纳/等级以上的面具」，AI 可写委托口吻（§20 风格），条件与奖励数据表。交出即面具消失（原作）。
- 天鹅绒羁绊按完成数升级，解锁顺序照 P5R 力量 COOP：三体合成 → 禁闭 → 特别处遇 → 四体以上合成 → 警报强化。
- 特别处遇：越级合成花心之力（额度数据表）。
- 禁闭：真实时间；关押中面具灰掉不可携带；释放后被动替换成补一项弱点的抗性（无弱点时给一项异常抗性，照 P5R）；心之力可提前释放。

### 4.4 合成警报（V9/V10）
- 触发：潜入结算后按数据表概率；有效至当天 24:00（Asia/Shanghai 按设备时区）。
- 期间：合成、献祭、道具化各一次强化（合成多继承、献祭系数高、电椅出高阶表）；同一设施第二次使用 = 事故：结果随机（合成随机面具、电椅随机道具），**确认弹窗写明会事故**。
- 演出：据点天鹅绒入口闪红门（FX `velvet:alarm`），事故 `fusion:accident`。

### 4.5 HOLD UP 三选一 + 交涉中索要（B4/B5）
- 包围后三项：总攻 / 交涉（目标：面具；可能附带 ¥/道具）/ 勒索（选要 ¥、道具或 SP 中一种，必成功但数额看敌人等级与魅力，数据表）。
- 交涉中阴影可能索要 ¥ / 道具 / HP：给 = 好感档位上升、拒绝 = 下降；全部按档位 → 成功率规则换算，AI 只给档位。
- 多敌（D-004）：只对「交涉对象」一只结算，其余在勒索/交涉成功后逃散（原作）。

### 4.6 羁绊战斗能力（B2/B16，C1）
- 每名同伴（按皮名单）1–10 级；能力按原作顺序解锁，四皮同表：扶起倒地队友 → BATON 加成层 +1 → 追击（主角打倒地后概率接一击，按原作会取消 1 MORE）→ 治异常 → 替主角挡致命一击 → 硬撑 1HP → BATON 加成层 +1 → 羁绊满：对应阿尔卡纳终极合成解锁。
- 概率与加成全部数据表；sim:balance 机器人 C 默认带「中等羁绊」跑一行、「零羁绊」跑一行，保证零羁绊也能达到 D-006 表。
- 演出：`bond:assist { kind: followup|protect|endure|cure|lift }`，每种 ≤0.8s，P5 漫画格、P3 塔罗闪、P4 黄底格。

### 4.7 换人 SWITCH（B8）
- 我方回合开始时可换 1 名同伴（不含主角）为替补，不耗行动；倒下的同伴也可换下。每回合限一次。
- 替补经验沿用 D-006；编队界面显示替补顺序。
- 演出 `party:switch` ≤0.5s（P5 剪影交换、P3 召唤器举起、P4 塔罗换卡）。

### 4.8 防御 / 逃跑 / 失败（B9/B10/B19）
- 防御：本回合受伤按数据表减免；被弱点命中不倒地、不给敌方 1 MORE。
