# P5 × P3 融合蓝图

> 用户目标：P5 的全套玩法 + P3 的爬塔，完美融合。
> 视觉基线：`outputs/battle-experience-v3/` 的蓝色主题、UI、动画、转场、排版。
> 开发顺序：先规则，后 UI；每个阶段先可测试，再接蓝色界面。

## 一句话

白天经营自己，夜里爬一座会读你的塔；塔里用 P5 的全套战斗、交涉与收服，塔外用人格面具监狱合成、用商店准备下一次攀登。

## 双核怎么融合

- **P3 是骨架**：一座常在的塔（影时间）、区层与路线、随机遭遇、Boss、日历/满月、社群、资源压力、爬塔后返回再准备。
- **P5 是器官**：弱点/1 More/Baton Pass/All-out/Hold Up、交涉收服、技术伤害、枪/道具/装备、主题层/潜行/宝箱/预告信、天鹅绒监狱、商店/经济、社群能力。
- **融合原则**：塔是唯一主舞台；每层是 P5 式“认知主题层”；战斗用 P5 规则；成长用 P5 Persona + P3 社群/日历；AI 负责生成主题、影子人格、事件、收服/融合提案。

## 核心循环

1. **白天**：记录/待办 → 五维、SP、钱、社群、商店/装备。
2. **夜里**：进塔 → 选路线 → 潜行/遭遇 → P5 战斗 → 1 More/Baton Pass/Hold Up → 交涉收服或拿奖励。
3. **层间**：宝箱、安全屋、商店、事件、Boss、预告信。
4. **回城**：结算钱/材料/面具 → 天鹅绒监狱融合/处刑/图鉴 → 商店补给 → 次日。

一层完整 run = 未来第一个垂直切片。

## Persona 命名规则

- Persona 名 = 神话 / 历史 / 文学人物 + 称号；不能用职能标签（观测者、反抗者、织线者）当最终名。
- 敌人影子可以有描述名；收服后归还真名（诡辩之影 → 普罗米修斯·诡辩，刻薄之影 → 厄里斯·刻薄）。
- 融合结果用大名字（卡戎·夜航、阿特拉斯·负重、倪克斯·潮汐、巴别·断塔）。
- 基础面具示例：奥丁·全知、须佐之男·斩蛇、赫尔墨斯·疾风、天照·守灯、卡门·回响；终极借来的面具：伊邪那岐·大神。
- AI 生成 Persona 时同样遵守：先选人物，再给称号；不得输出“某类人/某个标签”。

## 战斗系统清单

- 4 人小队（主角 + 3 名社群同伴），1–4 个敌人。
- HP/SP、近战、枪/弹药、Persona 技能、道具、防御、换面具。
- 弱点/抗性/无效/反射/吸收；1 More；Baton Pass；All-out；Hold Up；交涉；技术伤害；状态；暴击/倒地；敌人意图；Boss 阶段；Showtime（后期）。
- **当前 lab**：3 人/2 敌、1 More、Baton Pass、技术、枪、防御、换面具、Hold Up、交涉收服。
- **下一步**：第 4 名同伴、多敌目标、敌人意图、反射/吸收、Showtime；然后接蓝色战斗 UI。

## 天鹅绒监狱

- 场景：监狱、铁栏、双子看守；不是普通弹窗。
- 功能：双体融合、特殊合成、绞刑（献祭升级）、电椅（物品化）、禁闭（属性训练）、图鉴登记/取出、技能卡、网络合成。
- **当前**：双体融合/技能继承/图鉴/绞刑/电椅/禁闭规则 + 监狱 lab。
- **下一步**：补全 22 阿卡纳配方、特殊合成、技能卡；把收服到的影子接进名册。

## 商店 / 经济 / 宝箱

- 诊所（药品）、军品店（武器/护具）、自动贩卖机（SP 饮料）、后续旧货店/材料店。
- 钱（¥）、买/卖、装备加成、消耗品/材料、宝箱木/银/金/封印/陷阱。
- 元素封印箱必须用对应属性打开；陷阱箱先检查可免伤；宝箱掉落元素碎片，供 Persona 融合。
- **当前**：规则 + 7 项测试；城市 lab 待做。
- **下一步**：城市 lab（商店 NPC 背景切换/转场 + 宝箱 + 装备），最后再把这套 UI 收进蓝色基线。

## AI 的职责

- 影子人格、台词、条件、收服提案。
- 塔层主题、事件、规则变体、掉落候选。
- Persona 融合提案、技能变体、成长提议。
- 敌人意图/反制/记忆回声。
- 所有输出走白名单、结构化契约、超时/坏 JSON 回退；AI 不直接改 HP/SP；离线也有程序化变体。

## “完美还原”的边界

- 还原**系统与手感**，不照搬原作角色、文本、美术、音乐、店铺名。
- P5 是商业级体量；我们按垂直切片逐层验收，不一次性假装完成。
- 每个阶段先规则测试，再真实交互，再 UI；视觉最后统一到已验收的蓝色基线。
