## 1. 这次做了什么

现有页面还是 `p5-velvet-lab.html` / `p5-velvet-lab.js`，没有重做 UI。

数据链路改成：

```text
p5-velvet-lab.js
  → velvet-rules.js
  → p5r-compendium.js
  → p5r-compendium-data.js
```

其中：

- `p5r-compendium-data.js`：生成后的 P5R 数据文件
- `p5r-compendium.js`：按 ID/名称查询、二体融合、rare 融合、特殊融合、完整性检查
- `velvet-rules.js`：继续向页面提供原有的 `PERSONAS` / `fuse` / `register` / `withdraw` 接口
- `../../scripts/import-p5r-compendium.mjs`：数据转换脚本

页面 DOM、CSS、路由和操作流程未改。

## 2. 数值口径

按 2026-10-18 的最终要求，以下四类数据作为游戏数值保留：

- Persona 等级
- 力 / 魔 / 耐 / 速 / 运五项基础属性
- 物 / 枪 / 火 / 冰 / 电 / 风 / 念 / 核 / 祝 / 咒十项抗性
- 每个技能的学习等级

另外保留技能名、技能效果、SP 消耗、特性、电椅物品、特殊融合与 DLC 等结构字段。

当前 demo 的旧结果卡还需要 HP、SP、攻击、防御四项，因此：

- `stats.attack` 映射 P5R 的“力”
- `stats.defense` 映射 P5R 的“耐”
- `stats.hp` 沿用 demo 的 `30 + level`
- `stats.sp` 沿用 demo 的 `20 + level`
- 真正的五项 P5R 属性同时保存在 `sourceStats`

HP/SP 不会被标成 P5R 原作数值；伤害结算和后续平衡仍由本项目自己定。
