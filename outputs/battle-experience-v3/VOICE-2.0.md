# P5 交涉口吻 · 2.0

## 原则

- 交涉是“打服之后再谈”，不是心理审判。影子有欲望、有价码、有脾气。
- 影子先开口，玩家再选威胁 / 讨好 / 讲理 / 给 SP；每句话都要能听出人格。
- 台词短，带一点剧场感；不写现代心理学术语，不替玩家总结人生。
- 机制提示放按钮副行，不进入影子台词。
- 只学 P5 的交涉语气与舞台感，不复刻原作台词。

## 五种影子人格

| 人格 | 说话方式 | 吃哪一套 | 不吃哪一套 |
|---|---|---|---|
| 傲慢 | 抬下巴、反问、不肯先低头 | 讨好 | 威胁 |
| 怯懦 | 结巴、连说两遍、先求饶 | 威胁 | 讨好（没用） |
| 贪婪 | 三句不离价码、盯着 SP | 给 SP | 威胁 |
| 暴怒 | 短句、吼、还没打够 | 威胁（有一点用） | 讨好 |
| 冷静 | 慢、礼貌、像在等你先开价 | 讲理 | 威胁 |

## 四类回应

- 威胁：逼它认输。对怯懦者最有效，对傲慢者最危险。
- 讨好：给它台阶。对傲慢者最有效。
- 讲理：问它为什么守在这里。对冷静者最有效。
- 给 SP：20 SP 换一个机会。对贪婪者最有效。

## 台词示例

- 傲慢：“哼。你把我打倒，不代表你有资格和我谈。”
- 怯懦：“等等、等等！别打脸！你想要什么，我都可以谈！”
- 贪婪：“你身上有 SP 的味道。先拿出来，再谈条件。”
- 暴怒：“谈？我还没打够！你先把拳头放下。”
- 冷静：“你终于愿意停手了。坐吧，影子也是要面子的。”

## 收服与奖励

- 收服不是“加入队伍”这么简单：给面具一个名字、一个技能、一个它记得的瞬间。
- 奖励也不是纯数值：物品名要像从影子身上撕下来的东西。
- 失败要让玩家感到代价：它被激怒，下一击更重，或者把刚才的话反用回来。

## Persona 命名

- Persona 名必须是神话、历史或文学人物，可带称号；禁止用“观测者 / 反抗者 / 织线者”这类职能标签当最终名。
- 敌人影子可以有描述名（诡辩之影 / 刻薄之影）；收服后必须归还真名（普罗米修斯·诡辩 / 厄里斯·刻薄）。
- 融合结果用大名字：卡戎·夜航、阿特拉斯·负重、倪克斯·潮汐、巴别·断塔。
- 当前主战面具：亚森、皮克希、杰克灯笼、希路奇、女梦魔；借来的面具：伊邪那岐。
- 名字先像“从神话里走出来的人”，再考虑好不好念；不要像职业、功能或 UI 标签。
