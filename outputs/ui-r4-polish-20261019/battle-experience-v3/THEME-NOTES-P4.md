## 第四轮打磨（质感 / 手感，2026-10-19 收尾）
源：`p4src/95-polish-r4.css`（覆盖前面各层）+ `reload-p4.js`。规范见 /workspace/work/POLISH-R4.md。

**统一规则**：动效档 120/200/320/480ms；进入 expo-out `(.16,1,.3,1)`、退出 `(.7,0,.84,0)`；hover 位移 ≤3px、不缩放，只动 transform/opacity；标题最多 1 层无模糊硬阴影；全屏背景静态或 ≥20s transform 漂移，手机静态；reduced-motion 只留短淡入。

**转场**
- 场景切换只走一层：`.p4-tvx`（canvas 生成的静态雪花 PNG，WAAPI scaleY 显像管收拢，460/600ms）。新 DOM 在遮罩后重建，同一任务内盖上，再揭开。
- 只在 `#content` 真正重建时盖雪花（之前 hashchange 先触发一次、重建后再触发一次 → 两次雪花闪帧，已修）。
- app 的 `.sweep` 在 P4 下去掉不透明雪花底（原先 670ms 后 display:none 硬切，且和 `.p4-tvx` 叠成双层转场），只剩频道字一闪而过。
- 地图移动：新视口在首次绘制前同步居中（消除 tower-flow 两帧后才居中造成的一帧错位），`.map-grid` 再用 transform 从旧位置滑到新位置（320ms expo-out）。
- 390 帧测（rAF 间隔，>34ms 为长帧）：换页 1、进塔 0、楼层切换 0、遭遇开场 1–2、胜利回图 0、商店 0–1、天鹅绒 0–1、训练遭遇 1–2、设置弹窗 1。剩下的长帧是 app 同步重建 DOM（50–130ms 长任务），发生在雪花遮罩之后。录屏亮度逐帧检查无闪帧。

**零遮挡 / 零重影**
- 遮挡脚本（文字中心与两端 `elementsFromPoint`）全部页面 1440/390/320 = 0；三档无横向溢出；Console 无新增 error。
- 回合横幅 `.turn-handoff`：1.5s 后 `visibility:hidden`；reduced-motion 下改成 1.1s 淡入淡出（原先 `opacity:1` 常驻，会盖住敌人 HP）。
- 拉丁展示字体（Bebas/Caveat）变量补中文回落（PingFang/YaHei/Velvet），不再回落到系统 sans-serif（缺字时显示方框）。
- 手机地图 HUD 的 LIVE 红点原先压在 “L” 上，已修正位置。
- 据点五台小电视：说明文字底部留 10px，不再贴住屏幕下沿黑框；hover 时 SUPPLY 等标签保持黑字。
- 战斗指令 hover：原先黄底白字发虚 → 保持黑字，加左侧红色指示条，位移 3px。

**清理**：删掉调试开关 `window.__p4noCover` / `window.__p4noChoreo`。

**残留**
- 回合横幅（YOUR TURN / ALLY TURN）出现约 1.5s，期间会短暂盖住敌人名/HP 条（属于有意的全宽播报，结束后完全移除）。
- 中文落到 Velvet 字重时，HUD 里中文值（如“外环”）比 Bebas 数字轻一些。
- 楼层切换只用 debug `jump()` 测过，没走真实 DAWN 流程；地图移动时玩家标记跳到新格（镜头会滑动跟上，但标记本身不做补间）。
