P5R 红色主题 demo · 内嵌字体说明 / Bundled font notice
=======================================================

本目录全部字体文件均为 SIL Open Font License 1.1 授权字体的**修改版（子集）**，
由 scripts/subset-fonts.py 按 demo 源码实际用字（scripts/collect-chars.py 扫描 src/** 与 index.html）切出，
并已改名（name 表 family 改为 "P5R Demo …"），不使用任何 Reserved Font Name：

  p5r-sans-sc.woff2 / p5r-sans-sc-ext.woff2   ← Noto Sans SC（变量字，wght 100–900）
        Copyright 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.
        Copyright 2022 The Noto Project Authors (https://github.com/notofonts/noto-cjk)
  noto-sc-black-p5r/*.woff2 / p5r-black-fill.woff2 ← Noto Sans SC Black（同上版权）
  p5r-round-sc.woff2                           ← 寒蝉全圆体 ChillRoundF v3.200
        © 2023 ChillType，基于小杉圆体（Kosugi Maru, Copyright (C) 2010 MOTOYA CO.,LTD.）
        / justfont 粉圆 / 猫啃糖圆体；https://github.com/Warren2060/ChillRound

CSS 中的 font-family 名（'Noto Sans SC Black' / 'Velvet Sans SC' / 'Velvet Round SC'）只是样式表内的本地别名，
与真实仓库一致以便接入；字体文件内部名称已改。字体不得单独售卖；随本 demo 分发时须保留本文件。
子集外的字（用户新输入的生僻字等）按 CSS 回退链落到系统字体——demo 的刻意取舍；真实仓库用 GB2312 全量 + 生僻层。
